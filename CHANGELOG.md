# Changelog

## [1.0.0] · 2026-11-23

First public release.

### Added
- Windows agent (Node + TypeScript) with tray icon, encrypted WebSocket on the LAN and QR pairing.
- Android app: Apps, Decks, Screens, Audio and Pad tabs, portrait and landscape.
- Per-app volume, audio routing, now-playing with progress, default output.
- Screens map: turn on/off, send the active window, rename, reorder, identify.
- Decks: up to 32 pages with images and GIFs, export/import, sound keys through a chosen PC output.
- Scenes, global `Ctrl+Alt+…` shortcuts, start with Windows.
- Browser extension (MV3) for generic video control on any site.
- Installable Android APK build and portable Windows agent build.
